# Version 1.0.0 Release Notes

发布日期：2026-08-10

## 版本目标

Version 1.0 建立了一个可以安装、运行和测试的 Python 二维 2R 机械臂学习项目。它从机器人数据模型开始，逐步加入正运动学、静态绘图、角度滑块、工作空间、目标点击和末端轨迹。

## 已完成功能

- `JointLimits` 和 `TwoLinkManipulator` 数据模型。
- 连杆长度、关节限制和初始角度有效性检查。
- 二维二连杆正运动学。
- 理想圆环工作空间及目标可达性判断。
- Matplotlib 静态机械臂绘图。
- `q1`、`q2` 交互滑块。
- 鼠标目标点选择及状态显示。
- 末端执行器运动轨迹记录与显示。
- 三个可直接运行的示例。
- 数据模型、运动学、工作空间、绘图和交互测试。

## 验收结果

- pytest：36 项测试通过。
- Ruff lint：通过。
- Ruff format：通过。
- Python 3.12：已验证。
- 交互 Demo：已完成真实窗口和截图检查。

## 实现归属

项目自行实现机器人数据模型、输入约束、正运动学公式、理想工作空间判断、交互状态和轨迹记录。Matplotlib 提供绘图窗口、基础图元、滑块和鼠标事件。

## 已知限制

- 只处理理想二维几何模型，不包含动力学。
- 可达性判断暂不考虑关节限制。
- 没有逆运动学，点击目标后不会自动移动。
- 没有轨迹规划、控制器、碰撞检测或避障。
- 没有 ROS 2、Gazebo、MoveIt 2 或视觉模块。

## 下一版本方向

Version 2.0 将在保留数据模型、正运动学和可视化基础的前提下，逐步增加解析逆运动学、关节限制处理、轨迹规划、PID 控制和碰撞检测。进入 Version 2.0 前应先创建 `v1.0.0` Git Tag。
